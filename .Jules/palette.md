## 2026-06-27 - [Initializing Empty Repository with UX Standards]
**Learning:** Starting an empty repository with a high-quality placeholder, a skip-to-content link, and a descriptive README sets a strong accessibility and developer experience baseline for future contributions.
**Action:** Always include a skip-to-content link in the initial index.html even for simple placeholders to ensure immediate accessibility.

## 2026-06-27 - [Screen Reader Optimized Phone Numbers]
**Learning:** Screen readers often read long strings of digits as a single large number. Adding an `aria-label` with spaced digits (e.g., "0 9 6 0 6...") ensures the phone number is announced correctly and clearly to users.
**Action:** Always provide a spaced-out `aria-label` for phone numbers and other long numeric identifiers to improve clarity for assistive technology users.
