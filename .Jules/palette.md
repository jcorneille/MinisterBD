## 2026-06-27 - [Initializing Empty Repository with UX Standards]
**Learning:** Starting an empty repository with a high-quality placeholder, a skip-to-content link, and a descriptive README sets a strong accessibility and developer experience baseline for future contributions.
**Action:** Always include a skip-to-content link in the initial index.html even for simple placeholders to ensure immediate accessibility.

## 2026-06-27 - [Streamlined Interactive Feedback Pattern]
**Learning:** For simple sites, a concise "Copy to Clipboard" implementation can be achieved with under 10 lines of JS while still providing visual (text change), styling (class toggle), and accessibility (ARIA label) feedback. Combining these updates ensures a "smooth" feel without excessive code.
**Action:** Use a temporary text and ARIA label swap pattern for "Copy" buttons to provide immediate, accessible success feedback.
