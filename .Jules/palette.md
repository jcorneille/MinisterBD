## 2026-06-27 - [Initializing Empty Repository with UX Standards]
**Learning:** Starting an empty repository with a high-quality placeholder, a skip-to-content link, and a descriptive README sets a strong accessibility and developer experience baseline for future contributions.
**Action:** Always include a skip-to-content link in the initial index.html even for simple placeholders to ensure immediate accessibility.

## 2026-07-09 - [Interactive Hotline with Copy-to-Clipboard]
**Learning:** Combining a `tel:` link for mobile accessibility with a "Copy" button for desktop users provides a robust contact experience. Providing immediate "Copied!" feedback with ARIA label updates ensures the interaction is clear for all users.
**Action:** Use temporary text changes and ARIA label updates for "Copy to Clipboard" buttons to provide high-quality feedback.
