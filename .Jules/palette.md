## 2026-06-27 - [Initializing Empty Repository with UX Standards]
**Learning:** Starting an empty repository with a high-quality placeholder, a skip-to-content link, and a descriptive README sets a strong accessibility and developer experience baseline for future contributions.
**Action:** Always include a skip-to-content link in the initial index.html even for simple placeholders to ensure immediate accessibility.

## 2026-06-27 - [Micro-UX: Copy to Clipboard for Hotline]
**Learning:** Providing a "Copy to Clipboard" feature for key contact information like hotline numbers significantly improves user convenience, especially on mobile. Using temporary ARIA label updates ensures the feedback is accessible to screen readers.
**Action:** Implement "Copy to Clipboard" with both visual and ARIA feedback for all unique identifier or contact fields.
